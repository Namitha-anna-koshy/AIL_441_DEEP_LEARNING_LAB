# AIL 441 Deep Learning Laboratory

This repository contains the implementation of ten experiments completed as part of the **AIL 441 Deep Learning Laboratory** under the B.Tech program in **Artificial Intelligence and Data Science (KTU)**.

Each experiment explores key deep learning concepts, architectures, and techniques applied to both standard datasets and real-world problems.

---

## Contents

| Experiment No. | Title |
|----------------|--------|
| 01 | Linear Regression *(stored in separate repository)* |
| 02 | Image Enhancement |
| 03 | CIFAR-10 Image Classification |
| 04 | CIFAR-10 Classification with Hyperparameter Tuning |
| 05 | Convolutional Neural Network (CNN) Implementation |
| 06 | MNIST Digit Classification using VGG19 |
| 07 | Time Series Forecasting based on NIFTY50 |
| 08 | IMDB Dataset Review Classification |
| 09 | IMDB Review Classification using LSTM and GRU |
| 10 | English to Hindi Neural Machine Translator |
